发送脚本），或客户端在**未等响应就流水线式发下一帧**。

影响：
- 被 503 的帧**没有预测**（你们客户端按"本周期失败"保持）；
- **c20 与 c21 重叠窗口（22:38–22:42）的数据不可用于绕行结论**，c20 全段也因大量丢帧而可信度低。

请确认两件事：**①只有一个 VLM 节点在跑；②每个会话同一时刻只有一个未完成请求（等到响应再发下一帧）。**
