**关键是用"净空恢复即停转"闭环，而不是固定时长的开环转**。再补三点防止死角打转：

1. **加转角上限**：相对"进入避障时的航向"累积转角不超过 **±60°**（值你们定），
   防止在死角里持续转向绕圈。
2. **恢复阈值要带迟滞**：释放门限高于触发门限（如近侧恢复到 **≥1.0 m**、或所选侧 **≥1.2 m**），
