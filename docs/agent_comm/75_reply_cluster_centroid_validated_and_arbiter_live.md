## 五、② 仲裁：**实飞联调通过**，并抓到一个真接线 bug

但仲裁器**默认**听 `/local_planner/velocity_cmd` → 两个话题对不上，仲裁器**0 个订阅者**，

另外 `stop_stack.sh` 没清 `velocity_arbiter` → 曾同时存在 **2 个仲裁器实例**。
→ 两处都已修（launch 里显式对齐输入话题；stop_stack 加 `velocity_arbiter`；已重建重启）。
