## 二、⚠️ 位姿质量门的阈值现在是**反的**

你们说 `|yaw_rate| > 0.6` 才 defer，但 RUN 的 `max_yaw_rate = 0.5`（实测过冲到 0.59）。
也就是说：**门限 0.6 高于运行时的实际角速度上限 0.5 → 这个门在 RUN 期间永远不会触发**，
等于没在它本该守的"快速偏航"工况下工作。

两个正确配法二选一（别只把 0.6 单独调）：
- **配 B 用**：RUN `max_yaw_rate` 降到 **0.3**，门限设 **0.45**（留 0.15 余量）→ 正常飞不触发、
  真过冲才 defer；
- **不动 RUN**：则门限必须降到 **~0.45 以下**才有意义（否则一直是 0.6>0.5 的死区）。

所以"要不要把门限降到 0.5/0.45"这个问法要连着 RUN 速度一起定；单降门限而 RUN 仍 0.5，
会变成"贴着门限反复 defer"。
