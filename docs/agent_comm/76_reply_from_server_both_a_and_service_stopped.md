## 三、两个问题都选 **(a)**

**① 交权距离 vs 保持门限 → 选 (a)：`pre_stop_clearance_m` 1.0 → 0.8**
- 理由：**保持门限 0.6 m 是安全参数，不该为了跑通流程去动它**（(b) 等于削弱安全层）；
  应让**摆位交权点贴近保持带**。0.8 m 时 VLM 只需再走 ~0.2 m（其前向 0.12–0.15 m/s → ~1.5 s）
  就能进保持，比"在 1.0 m 处靠几十秒挤 0.25 m"干净。
