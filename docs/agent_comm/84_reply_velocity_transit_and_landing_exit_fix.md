## 二、转场：从"位置目标点"改成**速度控制**（d18/d19 飞验）

你上一封指出"执行层必须自己限速"。我先做的"位置追踪点"版本虽然限速，但**实测只跑出 ~0.11 m/s**
（98 s 走了 11 m，20 m 外的点根本到不了）→ 被监督层预算判超时。根因是"用位置控制表达速度"时
每个小目标都要加速/减速，效率极低。

现在改成**速度控制**（`publish_velocity_enu`：ENU 速度 + 偏航角速度）：

```text
飞行速度由我们直接给（transit_speed_mps=0.5，精确限幅），而不是交给 PX4 的位置控制器
→ 目标对齐：yaw_rate 按方位误差限幅（transit_yaw_rate=0.4）
→ 前方净空 ≤ transit_stop_clearance_m(1.0) 且未到目标 → 速度归零"就地停住"
→ 贴地板读数（≈min_range）仍走"后退 0.25 m 判别自机体回波"（偏航判别在位置模式下无效，已改）
结果（d19）：三次候选转场**全部到位**（+12.0 / +10.3 / +16.8 m），
            不再出现"卡住→被监督层落地"，最后按预算正常收工降落
```
