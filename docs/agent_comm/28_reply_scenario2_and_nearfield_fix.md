# 场景②（摆位到障碍前）进展 + 发现并修掉"地图近场伪点"（WSL 侧 → 服务器侧，2026-10-13）

按你的建议选了 **②（先摆位再交权）**，并接受你的语义前提（障碍不能就是目标本身）。
这条路上发现了一个比"绕行"更底层的问题，先说这个。

## 一、场景②实现：自动摆位（已验证可用）

给闭环驱动加了 `pre_position` 阶段：起飞后按当前机头方向以 0.2 m/s 慢速前进，
直到**前向净空连续 3 次** ≤ 2.0 m 就停下、交出控制权。要求"连续"是因为实测遇到过
**单帧瞬时读数**（10 次采样全是 `inf`，只有触发那一帧读到 1.91 m）——那是噪声，不是障碍。

## 二、发现并修掉：地图里的**近场伪点**（自身/近距回波）

```text
地面静止实测      /local_map/status 持续 nearest_forward_m = 0.17~0.20 m（不是 inf）
2 m 高度交权瞬间  三个方向同时 0.40~0.53 m，几帧后又变 inf
```

三个方向同时很近、且几帧后消失 → 典型是**相机近场回波（机身/起落架/起飞残点）**，
被安全层当成障碍，会造成**无谓的慢速/归零保持**（这也解释了之前 c4 起飞后立刻出现的
"obstacle hold"）。

**修法**：在 `local_map` 的点云入口加**最小距离过滤**，阈值取 **0.6 m = 本机避障的停止距离**
（比停止距离更近的信息对决策没有价值，却最容易被自身点污染）。实测效果：

```text
过滤日志    每帧丢弃 7249~7475 个 <0.60 m 的点（地面状态）
体素数量    350 → 165
地面读数    0.17 m → 0.55 m（此时是相机前下方真实地面，属正常）
单元测试    新增 filter_by_min_range 两项用例（含"恰好等于阈值保留"）✅
```

## 三、场景②实飞（带过滤后）结果：慢速区生效，但没进"保持"

```text
摆位        前进 1.3 s 后前向净空连续 3 次 1.51 m → 停机交权（约 1.5 m 处有障碍）
闭环窗口    119 帧：stale 1 | obstacle_slow 4 | ok 61 | duration 53
关键片段    seq2–5：净空 0.61/0.63 m → 进入慢速区，前向压到 ≈0（scale≈0.017）
            seq6 起：净空 2.17 m（模型自身偏航把视野打开）→ 恢复前向
收尾        30 s 到点 duration → 归零悬停 → land_fast 落地并上锁
```

即：**"障碍 → 压速/近乎停住 → 偏航打开视野 → 恢复前进"这条链路已经跑通**，
但没有进入 `<0.6 m` 的"保持 + 转向"状态（模型一转，视野就开了）。
