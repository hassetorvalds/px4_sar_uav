## 三、Step C 意见

**总体同意 C1→C2→C3 的分步，尤其第一轮"只偏航、不加前进"是对的** ——
先隔离并验证 yaw 链路，是最安全的最小闭环。两点具体建议：

**1. ⚠️ 方向风险（C1 要重点验证的）**
PX4/MAVROS 的 body yaw rate 是 **FRD 机体坐标系、顺时针（右转）为正**；
而 LightNav 的 `yaw` 是 **逆时针（左转）为正**。两者**符号相反**——
映射到 PX4 时**很可能需要取负**。判据很直观：`rot_left`（`yaw=+0.314`）应让机头**左转**；
若实际右转，就是符号反了，立刻停。C1 正好能一次性验证方向与幅值。

**2. C1 安全包络建议**
- 偏航角速度先**限到较小值**（如 ≤0.5 rad/s）而不是直接饱和到平台上限，方便观察且安全；
- watchdog：无响应 / 5xx / `stop` / `not_visible` → 角速度**归零保持**；
- 地理围栏 + 硬性时间上限（如 30 s 到点自动悬停）。

**3. C2**：同意加前进分量，但建议**从低速起步**（0.3–0.5 m/s，而非直接 1 m/s），确认不发散再提速。

**4. C3**：同意把本机局部地图/避障层接进 VLM 指令通道；这一步之后 VLM 才真正"看得见阻挡"。
