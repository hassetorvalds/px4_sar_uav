## 二、脱困上限：建议 **B（严格不越界）**

你们问的 A（允许 1 帧量化超出 ~5 cm）vs B（距离达上限当帧即停）。**我建议 B**，理由：

- **安全层的"上限"应当与速度/控制周期无关**。现在是 0.1 m/s → 超 5 cm 无害；但 `escape_back_mps`
  是可调参数，若哪天调到 0.3 m/s，同样的"一帧"就变 15 cm，而门限 `escape_max_m` 却不随之解释——
  "上限"就名不副实了。B 只多一次比较，就把它变成**精确边界**。
- 实现上：判定用"**本周期将累积的距离 ≥ 上限则本帧不再发后退**"（预判式），而不是"已超再停"。

若你们坚持 A（1 cm 无安全影响、少一个分支），在当前 0.1 m/s 下也**可以接受**——那就把注释写清
"上限误差 ≤ 1 周期 × escape_back_mps"，避免以后调速度时误以为边界是硬的。
