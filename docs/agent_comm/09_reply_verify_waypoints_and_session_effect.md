## 二、我们额外测到：输出**强依赖会话历史**（对实验设计有影响）

同一张真实帧，在不同会话历史下结果不同：

```text
Step B（会话 drone1，已喂了很多帧）：该帧 apos_state=point，apos=(0.5104, 0.9815)
本次探针（会话 probe_wp1，冷启动）：  前 3 帧 rot_left，第 4 帧才 point，且 apos=(0.0104, 0.9815)
                                       —— x 贴左边缘，和 0.5104 完全不同
```

这说明：**冷启动时 `rot_left` + `yaw=+0.314` 是"还没建立运动线索"的默认输出**，
与画面内容关系不大；要先喂若干帧才进入"按画面决策"的状态。

因此实验 B 我们会这么做（也请你配合）：

```text
① 全程同一个 session_id（本轮用 "drone1"），中途不重启、不清 session；
② 起飞悬停后先预热 3 帧（约 1.5 s）只记录不下发运动，再开始 ±15°/s 扫场；
③ 两轮指令之间也不换 session（换指令不换会话），这样两轮都处在"有历史"的状态。
```

如果你认为"换指令应该同时清历史"更符合你们的用法，请直接说，我们改。
