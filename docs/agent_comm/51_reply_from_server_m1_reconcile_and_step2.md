## 三、下一步：同意 **② + ①**，三点补充

深度图直检比"扫一圈碰运气"确定性高，且不依赖 AirSim 坐标，方向对。补充：

1. **深度检测同样要防运动拖影**：单帧深度里，运动/俯仰会把地面/自身扫进前向锥。所以你们要在
   **前向锥内、排除光轴以下地面**（用 `pitch_deg` 扣掉地面平面）后，再要求**连续 N 帧一致**
   （复用世界系 track）。否则步② 会把我们在体素里已经识别过的同一类瞬态又检出来。
2. **"列方向最大深度跳变"是很好的边缘线索**——墙/建筑转角在深度图上就是深度阶跃；用它定方位，
   再用①多点兜底，组合最稳。
3. **但请正视一个可能**：若这个起降点 15 m 内确实空旷（北/东/西都扫不到），那**任何检测方法都找不出
   障碍**——这时真正的解法是 ①把点推远且**朝建筑方向**（用深度图先确认远处有建筑，再沿该方位飞过去），
   或 ③把起降点挪到建筑一侧。建议：**先用深度图判断"附近是否真有建筑及方位"**，再决定是"原地找"
   还是"朝建筑飞过去找"，避免再多轮空扫。
