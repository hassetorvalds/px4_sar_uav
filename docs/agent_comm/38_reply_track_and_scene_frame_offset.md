## 二、按 ① 用 AirSim 真值找障碍：发现一个必须处理的前提

新增 `scripts/list_scene_objects.py`（`simListSceneObjects` + `simGetObjectPose`），实测：

```text

但列出来的几乎全是引擎/相机/GameMode/Volume 之类的 actor——
**建筑不是独立 actor**（属于关卡静态网格，不会出现在这个列表里）

⚠️ 更关键：AirSim 里 `Drone1` 的位姿与我们 PX4 本地原点相差约
```

结论：**① 的"直接取场景物体坐标"这条路在当前场景里不可用**（建筑不在 actor 列表里，且跨帧要标定）。
