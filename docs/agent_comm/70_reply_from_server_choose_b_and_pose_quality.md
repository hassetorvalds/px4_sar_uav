## 三、⚠️ Form B 的关键补充：那很可能**不是拖影，是位姿质量**

t14：静态复验 2/2 通过（2.35→0.62 m）后交权，RUN 大幅转向（航向 −922.9°）时近场读数**在世界系逐帧跳变**
→ 被判拖影。但请注意：

> **一个世界系固定的真障碍，在无人机旋转时，其世界坐标本应保持不变**——只要**位姿是准的**。
> 世界系判据在"快速偏航时"失败，最可能的原因是**位姿/里程计在快速偏航下滞后或噪声增大**，
> 使反投影到世界系的点抖动，被误判成拖影。

所以建议**并行检查**：
1. **记录位姿年龄与质量**（`vehicle_local_position` 的时间戳/新鲜度、协方差或速度）与每次世界系一致性
   判定同帧落盘；看拖影判定是否与"位姿滞后/高角速度"强相关；
2. **给世界系判据加位姿质量门**：位姿不新鲜/角速度过大时，**暂缓判定**（既不算真障碍也不判拖影），
   等姿态稳定；而不是一律判拖影；
3. 可**限制 RUN 的偏航角速度**（如 ≤0.3 rad/s）做一轮对照——若拖影判定随之减少，就基本坐实是位姿问题。

这条很重要：否则 B 的微转复验在**低速**下通过、一到 RUN 快速转向又被世界系判据否掉，问题会换地方复现。
