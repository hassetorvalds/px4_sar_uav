# ⚠️ 安全事件复盘 + 两个更正：贴近障碍的风险、盲区底线、以及"重启 PX4＝复位世界"是错的

## 一、发生了什么（用户现场发现）

用户观察到：**AirSim 并没有复位**，而且**测试过程中飞机多次贴近/疑似蹭到障碍物**。
这**不是计划内的**，我先停飞核查。

## 二、核查结果（数据说话，含我自己的判断更正）

**1) 贴近障碍是真的，但根因不是你的"前向下限"，而是既有的保持态 creep。**

```text
今日 9 轮记录里，"净空 ≤0.5 m 且仍在前进"的帧按 guard 拆开：
  dry_run        1448 帧  ← **未交权**，飞机由摆位脚本控制；这里的前进只是 VLM"打算发"的指令
  idle            439 帧  ← 同上（未在控制）
  obstacle         30 帧  ← **保持态的 creep(0.05 m/s)**，既有设计：朝宽侧小前向绕行
  obstacle_slow     1 帧  ← 我新加的"前向下限"实际只影响 1 帧
```

**根因**：`local_map` 的 `min_range` 过滤（0.45 m）会把更近的点当自机体回波丢弃
→ **净空读数在 0.45 m 处触底**（今日所有轮次的最小净空都恰好 0.45 m）。
"看不见"不等于"没有障碍"——而保持态的 creep 仍以 0.05 m/s 前推，贴着大面时就可能蹭上。
这是我应该提前想到的：**引入任何"让他继续前进"的改动前，必须先问"传感器在更近处还能不能看见"**。

**2) AirSim 侧的最后一次碰撞记录是地面。**

```text
simGetCollisionInfo(Drone1) → has_collided=True, object_name=**Ground_5**, penetration=0.0
（更像 land_fast 落地触地；但 AirSim **只保留最后一次**碰撞，此前若蹭到建筑会被覆盖 → 无法追溯）
```

**3) 更正："重启 PX4 会把 AirSim 复位到出生点"是错的。**

```text
实测：AirSim 世界坐标 (北 23.4, 东 -22.6, 下 0.68)，而 PX4 报 x≈0,y≈0
⇒ PX4 重启只是把**本地坐标原点**重新设在飞机当前位置，飞机在世界里没被搬回去。
（我先前据此说"每轮起点一致"，是错的；这也解释了 d6–d9 命中率忽高忽低——飞机是接着上一轮落点起飞的。）
```

## 三、已落地的安全修正：**盲区底线**

```text
新增 obstacle_blind_zone_m（默认 0.5 m）：
  净空 ≤ 0.5 m 时 → **前向一律归零**（保持态也不再 creep，前向下限也被压掉）
  但**保留偏航**（继续朝更宽一侧转，把视野打开）
  落盘 guard_detail['blind_zone']；单测 +2 → **64 passed**
```

即：**够不着就别再往前凑，只转不推**。这条比原设计更保守，且不依赖"盲区里还有没有东西"的判断。
