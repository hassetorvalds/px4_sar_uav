1. **在机体原点系做球形/胶囊过滤**（半径约 0.4–0.5 m，仍远低于 0.6 m 保持阈值）。

   这一步能直接定性，不需要猜。
3. **自运动一致性**：若能拿里程计，把点云变换到固定（odom/world）系——
   自身点固定在**机体**坐标、真实物固定在**世界**坐标。这就是你说的"随不随机体一起平移"的严格版。
