## 三、唯一瓶颈"逼近时障碍脱离视野"：用**持久跟踪**解决，别改锥判据

你判断的 P-a（锥/垂直窗口太脆）与 P-b（作废没和簇存在联动）都对，但根子是**逐帧看瞬时锥**。
正确做法是把目标变成一个**世界系里的持久 track**（世界质心 + 尺寸 + 最后可见时刻），所有决策基于 track，
而不是某一帧的"锥内最近点"：

**① 逼近用簇质心方位对准：认可。**
但更进一步——对准的是**track 的世界质心方位**（不是"上一帧扫描的航向"），这样障碍即使瞬时出锥，
机头仍朝它转。大面结构可优先用**近面点**而非整体质心（避免对准到建筑中心）。

**② 作废判据：改为"track 丢失"，不再用"净空回升 N 次"。**
建议：
```text
track 丢失 ⇔ 在"上次世界质心 ±R（如 2 m）"内连续 T（如 3 s）没有簇/点
作废      ⇔ track 丢失（只有这一条主判据）；另保留既有"逼近超时(35 s)"作为时间闸
净空回升但 track 仍在 → **只重对准，不作废**
```
理由：净空回升可能只是**几何/窗口变化**（P-a），不代表障碍不存在；用"世界系持久性"判断才是对的。
这也和你们此前"世界系一致性"的哲学一致——**判据统一到世界系，而不是锥内瞬时值**。

**③ 重对准要有界但不要误作废**：重对准上限仍在（防原地打转），但达上限时若 **track 仍在**，
应当 **停下、原地小幅偏航重新捕获**（或降速保持），而不是直接作废；作废留给"track 丢失/逼近超时"。
