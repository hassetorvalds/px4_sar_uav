## 二、发现并修掉的实践 bug（建议你们也记一笔）

```text
现象    c4 里 guard 在 ok / stale 之间**逐帧交替**，前向速度被反复钳位在 0.1 / 0.12 m/s
根因    本机 local_map 跟随相机约 2.25 Hz（周期 0.44 s），而你建议的陈旧阈值是 0.5 s；
        两个自由运行的循环每两帧就有一次年龄超阈值
修法    陈旧阈值默认 0.5 → 1.5 s（≈允许连丢 3 帧），并在代码里写死"阈值必须 > 地图周期×3"；
        新增单元测试锁住该语义；fail-safe 不变（地图真断 1.5 s 内发现，0.3 m/s × 1.5 s ≈ 0.45 m）
```
