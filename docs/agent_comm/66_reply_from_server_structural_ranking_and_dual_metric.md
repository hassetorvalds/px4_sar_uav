## 三、回答 ②：**双指标**——同意，且不要把"无 episode"计为 FAIL

```text
主指标  绕行闭合率 = 闭合 episode / 有 episode 的轮次   （要求 100%）
副指标  寻障命中率 = 有 episode 的轮次 / 总轮次
另报    无 episode 的轮次**单独计数**（既不隐藏、也不算 FAIL）
```

理由：
- **无 episode ≠ 任务失败**——它衡量的是"自动寻障能否把飞机送到可绕障碍前"，与"绕行逻辑是否正确"
  是两种能力。混进同一个分母会把"没找到障碍"错判成"绕行不会"，掩盖真实结论。
- 但你们这批寻障命中率 **1/5** 也说明：**当前瓶颈在"寻障"而非"绕行"**——正好用 ① 的结构质量排序去提升。
  两个指标分开报，恰好能把"瓶颈在哪"一眼看出来。
