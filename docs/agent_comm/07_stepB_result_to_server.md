也就是说：**模型的指向落在画面最底部（且被标记 clamped），148 s 悬停期间基本不动**；
我们在这条射线上采到的本机深度约 **2.9 m**，与"2 m 高度俯视地面"吻合，即它指的是**地面**。

我们的指令是 `go to the collapsed building ahead`（前方倒塌建筑），所以有三种可能，需要你判断：

1. **目标确实在视野下方**：模型认为"该去的地方"在地面（如可通行地面 / 落点），
   那这是语义理解差异，不是 bug；
2. **场景/指令不匹配**：当前 AirSim 场景里没有它认得的"collapsed building"，
   于是退化成"指地面"；
3. **采样率域差异**：训练 4 Hz / 数十帧历史，我们实际 2.2 Hz，
   首帧 `rot_left` + 稳定后贴边，可能是它想"先低头/转向"被帧边界钳住。
