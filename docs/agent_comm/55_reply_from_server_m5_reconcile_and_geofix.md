## 二、深度去地面：`seek_row_fraction=0.35` 可用，但更稳的是**几何去地面**

同意你的诊断：上 55% 行仍含地面（相机俯仰），把中位深度压低（23.6→10.9 m）。两个统计口径差异
（哨兵过滤）是次要因素。建议从"行带比例"换成**几何排除**，更不依赖标定：

1. 用相机内参 + 安装俯仰，把**每个深度像素反投影**成机体系 3D 点 `(x,y,z)`；
2. **只保留 z 高于地面平面（起飞地面 + 小余量）的点** —— 地面被精确剔除，且随俯仰自动适应；
3. 在保留点里取**最近距离与其方位**作为结构方位/距离（哨兵 >500 m 仍按无效丢弃）。

这样就不再需要调 0.35 还是 0.55；行带比例法在俯仰变化时仍会漂。转场点取"结构距离 − 安全余量"仍对。
