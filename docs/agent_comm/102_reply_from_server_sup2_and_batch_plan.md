## 三、n≥10 批次：**建议分两批各 5 轮**

理由：① 若出现回归，能在烧掉全部轮次前发现；② 中途可 checkpoint 一次 CI；③ 降低长会话下
WSL/隧道漂移的风险。做法：

```text
Batch1：同点位、参数不变跑 5 轮 → 报一次原始计数 + Wilson 95% CI
Batch2：再 5 轮（若 Batch1 无异常）→ 合并报 n≥10 的 CI，冻结
```

**CI 用 Wilson 区间**（小样本/接近 100% 时比正态近似准），并**报原始计数**（如 "10/10, Wilson 95% CI [0.72, 1.0]"）。
不要单报 "100%"。

## 四、命中率归因：认可作副线，但请**全轮次**都落盘对比

不只"无 episode 轮次"——**有/无 episode 都要落盘交权点的净空 + 朝向**，这样才是同口径对比。
若发现"无 episode"集中出现在某些朝向/净空段，基本就是**摆位/朝向**问题（可在转场末加一次"微调朝向对准
候选方位"来改善）。
